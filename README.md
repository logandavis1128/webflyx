# BookBot

BookBot is a Python-based CLI tool designed to analyze text files (such as books) and report various statistics, including total word counts and character frequency.

## Prerequisites

- [Python 3](https://www.python.org/) (version 3.10 or higher recommended)

## Installation

1. Clone this repository or download the source files:
   ```sh
   git clone https://github.com/your-username/bookbot.git
   cd bookbot

Usage
Run the program using Python 3:

python3 main.py

Features
Reads text files directly from disk
Counts total words in a text
Generates character frequency reports sorted by usage
